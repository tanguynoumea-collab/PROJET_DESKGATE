- `Level = Literal["ok", "avertissement", "echec"]` ; `@dataclass(frozen=True) class Check: name: str; level: Level; message: str`.
- `def check_config(path: Path) -> tuple[Check, RunnerConfig | None]` ; message ok « <chemin> valide » ; en échec,
  ajouter « (un runner lancé par la tâche n'affiche pas cette erreur : lancez `deskgate serve` en console pour la voir) ».

- `def check_port(cfg, *, timeout: float = 2.0) -> Check` : `urllib.request.urlopen(f"http://{cfg.host}:{cfg.port}/health", timeout=timeout)`
  (`# noqa: S310`, http local) ; 200 et `status == "ok"` → ok « runner joignable (version X) » ; sinon
  (OSError, TimeoutError, JSON invalide) tenter `socket.bind((cfg.host, cfg.port))` sur un socket
  `SO_EXCLUSIVEADDRUSE` puis le fermer : succès → ok « port N libre (runner arrêté) » ; OSError → échec
  « port N occupé par un autre programme ».
- `def check_plugins(cfg) -> list[Check]` : pour chaque capacité `kind == "python"`, `Path(cap.python).is_file()` ;
  si `"bcf_executable" in cap.settings`, `Path(str(...)).is_file()` ; pour chaque `mcp_servers`, `Path(command).is_file()` ;
  aucun → ok « aucune capacité déclarée » (avertissement si `capabilities` vide).
- `def check_home_env(environ: Mapping[str, str] | None = None) -> Check` : avertissement si `DESKGATE_HOME` défini.
- `def run_all(home: Path, config_override: Path | None = None, *, with_task: bool = True) -> list[Check]` :
  home_env, config (arrêt si échec), dirs, token, `check_task()` si `with_task` (Task 2 ; en Task 1 écrire
  `check_task` minimal qui renvoie un échec « tâche absente » si `query_task_xml` renvoie None), port, plugins.
- `def exit_code(checks) -> int` : 1 si un échec, sinon 0.
`cli.py` : commande `doctor [--config PATH]` : `checks = doctor.run_all(resolve_home(), config)` ; une ligne par
check sur stdout : `[ok] Nom : message`, `[avertissement] …`, `[échec] …` ; `raise typer.Exit(doctor.exit_code(checks))`.
`tests/unit/test_doctor.py` (`pytestmark = pytest.mark.unit`) : configuration fabriquée par
`installer.init_config(home, root, force=False, now=datetime(2026, 10, 21))` dans tmp_path ; `with_task=False`
pour les cas sans tâche ; port : fixture `free_port` ; runner factice = `http.server.ThreadingHTTPServer`
sur 127.0.0.1:0 dans un thread (réponse JSON), arrêté en `finally` ; port occupé = socket `listen()` sans accept.
Réécrire le port de la config par remplacement de `port = 8765` dans le runner.toml de tmp.
