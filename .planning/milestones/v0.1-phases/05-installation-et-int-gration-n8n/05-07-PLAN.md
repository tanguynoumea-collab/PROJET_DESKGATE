- `GET /healthz` → 200.

  `waiting|success|error|running`, `waitTill`) ; `GET /api/v1/executions/<id>?includeData=true` →
  `data.resultData.runData["<nom du nœud>"][0].data.main[0][0].json` ; `POST /api/v1/workflows/<id>/activate`.
- `POST /webhook/deskgate-ifc-clash` → 200 `{"message":"Workflow was started"}` ; 404 tant que le webhook n'est pas enregistré.
CLI n8n dans le conteneur (`exec -T -u node n8n n8n ...`) : `import:credentials --input=/dev/stdin`,
`import:workflow --input=/tmp/ifc-clash.json`, `publish:workflow --id=DeskgateClash0001` (effet après `restart n8n`).
Base runner (lecture seule) : `jobs(seq, id, capability, status, error_code, created_at, started_at, finished_at, callback_url SECRET)`, `callbacks(job_id, state, attempts, ...)`.

nœud « Echec ou delai » `{resultat, job_id, erreur}`.
