> Per-phase validation contract for feedback sampling during execution.

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | pytest 9.1.1, plugin `anyio`, `--strict-markers`, `--import-mode=importlib` |
| **Config file** | `pyproject.toml` `[tool.pytest.ini_options]` (marqueurs : unit, fs, proc, e2e, bim, mcp, scheduler, docker) |
| **Quick run command** | `uv run pytest -m "unit or fs" -x -q` |
| **Full suite command** | `uv run pytest -q -W error::ResourceWarning` |
| **Estimated runtime** | ~360 seconds (suite complète : ~230 s hors e2e + ~115 s e2e) |

---

## Sampling Rate

- **After every task commit:** Run `uv run pytest -m "unit or fs" -x -q`
- **After every plan wave:** Run `uv run pytest -m "not scheduler and not docker" -q`
- **Before `/gsd:verify-work`:** Full suite must be green (scheduler inclus, `-W error::ResourceWarning`)
- **Max feedback latency:** 60 seconds (commande rapide)
